

# ProcView

A Windows Forms application built with C# and .NET that provides a simple way to monitor and inspect running processes on your computer.

## Features

- **Process Monitoring** – View currently running processes.
- **Process Search** – Search through running processes.
- **Process Details** – View information about selected processes.
- **Memory Monitoring** – Display memory usage for individual processes.
- **Dashboard** – View process statistics, including total process count and memory usage.

## Built With

- C#
- .NET
- Windows Forms
- Visual Studio
